# 🌎 TravelMate

![TravelMate Banner](https://images.unsplash.com/photo-1436491865332-7a61a109cc05?q=80&w=2074&auto=format&fit=crop)

**TravelMate** is a modern, feature-rich travel companion application designed to make your journey seamless and unforgettable. Built with React and Vite, it brings a sleek user interface and powerful tools right to your fingertips.

---

## ✨ Features

- **🤖 AI Trip Planner**: Generate personalized itineraries based on your preferences and travel style.
- **🗺️ Live Tracker**: Real-time tracking of your journeys and flights.
- **💵 Price Predictor**: Smart insights on flight and hotel price trends to help you book at the right time.
- **🧭 Explore Destinations**: Discover hidden gems and popular spots tailored for you.
- **📅 Smart Itinerary**: Manage your day-to-day plans effortlessly.
- **🎒 My Trips**: Keep all your past and upcoming adventures in one place.

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine. We recommend using `pnpm` for managing dependencies.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kamleshkumaryadav5951-pixel/TravelMate-Mobile.git
   cd TravelMate-Mobile
   ```

2. **Install dependencies:**
   ```bash
   pnpm install
   # or npm install / yarn install
   ```

3. **Start the development server:**
   ```bash
   pnpm dev
   # or npm run dev
   ```

4. Open your browser and navigate to the local server address provided in the terminal to see TravelMate in action!

## 🛠️ Tech Stack

- **Frontend Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Language**: TypeScript

## 📂 Project Structure

- `src/screens/` - Contains all the major views (Home, Explore, AI Planner, Live Tracker, etc.)
- `src/components/` - Reusable UI components like the Bottom Navigation.
- `public/` - Static assets like images and icons.
